## 👋 About me

I'm Hardik. I build machine learning systems, mostly around multimodal retrieval, document understanding and graph neural networks, and I like taking them all the way to something people can click on: an API, a dashboard, a working app.

Lately I've been spending most of my time on research-style work where the evaluation matters as much as the model. That means controlled benchmarks, baselines that are hard to beat, and checking whether a model learned the task or just a shortcut.

## 🧩 What I work on

> My pinned repositories below show what I'm building right now. Click an area to see what I do in it.

<details>
<summary><b>🔬 Multimodal AI and retrieval</b></summary>

<br/>

Systems that connect text with images, charts and 3D content. Embedding and fusing different kinds of data, building vector search, and using vision-language models to describe and reason about visual content.

</details>

<details>
<summary><b>📄 Document AI</b></summary>

<br/>

Getting structure out of messy documents: entity extraction, OCR, chart and figure understanding, and grounding claims in the parts of a document that support them.

</details>

<details>
<summary><b>🕸️ Graph neural networks</b></summary>

<br/>

Turning problems into graphs and learning on them with models like GAT and GraphSAGE, from link prediction to node classification.

</details>

<details>
<summary><b>🤖 LLM apps, RAG and agents</b></summary>

<br/>

Chatbots and assistants that answer from real documents, route requests between specialised agents, and hand off to a person when they should.

</details>

<details>
<summary><b>⚙️ Backend and full-stack</b></summary>

<br/>

APIs, microservices, real-time features and the web UIs that sit on top of my ML work, so a model ends up as something people can actually use.

</details>

<details>
<summary><b>📏 Evaluation and reproducibility</b></summary>

<br/>

Strong baselines, controlled benchmarks, significance tests, and checking whether a model learned the task or a shortcut. I try to make every number re-computable from one script.

</details>
